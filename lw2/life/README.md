# Команды для запуска

## Создание клеток

```bash
./cmake-build-debug/life generate ./test/test.txt 10 10 0.6
```

## Следующее поколение

```bash
./cmake-build-debug/life step ./test/test.txt 10 ./test/test2.txt
```

## Визуализация

```bash
./cmake-build-debug/life visualize ./test/test.txt 10
```
